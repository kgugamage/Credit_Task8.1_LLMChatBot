# Credit Task 8.1 - LLM ChatBot

This is an Android chatbot app for Credit Task 8.1.

## Features

- Username login screen
- Chat screen
- User messages and chatbot replies
- SQLite chat history
- Timestamps on messages
- RecyclerView message list

## How It Works

The user enters a username and presses the Go button. The app then opens the chat screen.

On the chat screen, the user can type a message and press send. The message appears in the chat with a timestamp. The chatbot then gives a reply.

All messages are saved using SQLite, so old messages can still be shown when the app is opened again.

## Technologies Used

- Android Studio
- Java
- SQLite
- RecyclerView

## AI Use

ChatGPT was used to help understand the task, create parts of the app, fix errors, and prepare the explanation.
